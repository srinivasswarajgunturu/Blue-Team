
## SOAR EDR Project

## Objective

The objective of this project was to design and implement an end-to-end automated incident response workflow using SOAR and EDR technologies in a cloud-hosted environment. A Windows Server deployed on Vultr was monitored using EDR telemetry to detect suspicious credential access behavior generated by password recovery tools such as LaZagne.

Upon detection, automated workflows were triggered to perform triage, notify analysts, request human approval, and execute response actions such as endpoint isolation. This project demonstrates how EDR detections can be operationalized into SOAR-driven response workflows in a real-world cloud infrastructure.

---

## Skills Learned

- Cloud-based Security Orchestration, Automation, and Response (SOAR) implementation
- Endpoint Detection and Response (EDR) telemetry analysis on cloud-hosted Windows servers
- Detection engineering for credential access and password recovery tools (LaZagne)
- Automated incident triage and response workflow development
- Secure monitoring of cloud-hosted endpoints accessed via RDP
- Integration of SOAR platforms with EDR telemetry sources
- Interactive incident response using human-in-the-loop approval workflows
- Translating endpoint detections into automated containment actions
  
---

## Tools Used

* Tines – SOAR platform used to design and execute automated incident response workflows
* LimaCharlie – EDR platform used to collect endpoint telemetry and create custom detection rules
* Vultr – Cloud platform hosting the monitored Windows Server
* Slack – Communication layer for real-time alerts and analyst decision prompts
* LaZagne – Password recovery tool used to generate credential access telemetry
* Remote Desktop Protocol (RDP) – Secure administrative access to the cloud-hosted server
* Email Service – Notification channel for incident awareness and response updates

## Learning Outcomes
By completing this Active Directory Detection Lab, I:
- Deployed and secured a cloud-hosted Windows Server for EDR monitoring and SOAR integration
- Generated realistic credential access telemetry using LaZagne to validate detection logic
- Developed custom EDR detection rules to identify suspicious password recovery activity
- Built SOAR playbooks that automatically ingest EDR alerts and initiate incident workflows
- Implemented human-in-the-loop decision points before executing containment actions
- Executed automated response actions such as alerting and endpoint isolation
- Improved understanding of cloud-based endpoint monitoring and SOAR-driven incident response
- Strengthened ability to design, document, and refine SOC automation workflows
